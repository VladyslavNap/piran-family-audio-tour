# Володарі солі — сімейна аудіоекскурсія Піраном

Публічний статичний PWA: карта Leaflet + OSM, GPS, 10 аудіозупинок українською.

## Як працює

1. Відкрийте сайт на телефоні (потрібен **HTTPS** для геолокації).
2. Натисніть **«Увімкнути звук і геолокацію»** — один дотик розблоковує автоплей і запитує GPS.
3. Ідіть маршрутом (~2.8 км). Коли ви входите в радіус ~50 м біля зупинки, аудіо запускається **один раз за сесію**.
4. Будь-яку зупинку можна слухати вручну з маркера на карті або зі списку внизу.

## Локальний перегляд

З кореня цієї папки:

```bash
npx --yes serve -l 4173 .
# або
python3 -m http.server 4173
```

Відкрийте http://localhost:4173  
Геолокація на `localhost` зазвичай дозволена; на звичайному `file://` — ні.

## Деплой (Netlify)

- `netlify.toml` уже налаштований: `publish = "."`, заголовки безпеки, MIME для MP3.
- Підключіть репозиторій до Netlify або виконайте `netlify deploy --prod --dir=.` з цієї директорії.
- Після деплою поділіться публічним URL з родиною.

## Структура

- `data/stops.json` — 10 зупинок у порядку візиту
- `data/route.geojson` — трек з GPX
- `audio/*.mp3` — озвучка
- `js/` — карта, геозона (haversine), плеєр
- `sw.js` + `manifest.webmanifest` — встановлюваний PWA

## Примітки

- Автоплей лише після розблокування (політика браузерів).
- Якщо кілька зупинок перекриваються (кластер на площі), обирається **найближча**.
- Плитки карти з OSM потребують мережі; оболонка й аудіо кешуються service worker’ом.
